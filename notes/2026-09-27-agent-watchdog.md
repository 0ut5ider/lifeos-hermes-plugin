# Agent watchdog compatibility

The isolated `.212` LifeOS install started from commit `5e2f2e8`. Its `AgentInvocation.hook.ts` writes active records to `LIFEOS/MEMORY/OBSERVABILITY/agent-starts.json`, while `AgentWatchdog.ts` read `subagent-starts.json`. No installed hook wrote the latter. Pulse also asked the model to call Claude's `Monitor` tool for a background agent; Hermes has no such tool.

The separate [LifeOS watchdog patch](../patches/lifeos-agent-watchdog.patch) changes the default starts file to `agent-starts.json`. It adds environment overrides for the starts file, activity file, silence threshold, and check interval. The defaults remain a 90-second silence threshold and a 15-second check interval. Hermes sets per-session file paths and replaces the Claude-specific status advice. A direct Bun test used isolated fixture files and saw the alert.

The [bridge](../lifeos_hook_bridge/bridge.py) starts the patched native watchdog as a Hermes tracked process when Pulse requests it in a background Agent hook. A bridge thread mirrors active Hermes async delegations for that parent session into the starts file and updates the activity file from Hermes progress timestamps. Hermes watches the process output for `WATCHDOG:` and routes a match through its background process notification path. The bridge replaces Pulse's `Monitor(...)` instruction with a truthful Hermes delivery message.

An isolated probe on `.212` dispatched a real Hermes async delegation record with a held synthetic worker. The native watchdog emitted `WATCHDOG:` and Hermes queued a `watch_match` event addressed to a synthetic Discord chat. The probe released the worker and stopped the watchdog. No process remained. Hermes's focused watch-pattern and gateway-notification tests passed 51 cases after the pinned test-only `pytest-asyncio` dependency was supplied from the local machine; `.212` could not download from PyPI under its outbound rules.

This verifies hook execution, registry state, process output matching, and route metadata. Actual Discord delivery is not verified in the test account because `.212` has no Discord bot connection. Hermes notification preferences can suppress background process alerts. A gateway restart can still interrupt the bridge's in-process state mirror; a later background Agent call can replace an orphaned tracked watchdog process.
