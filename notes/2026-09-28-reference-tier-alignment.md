# Claude reference child effort alignment

Date: 2026-09-28. The isolated `.212` Claude Code reference child adapter forced every LifeOS tier to medium effort. The Hermes plugin maps Haiku to low, Sonnet to medium, and Opus and Fable to xhigh. This made model-dependent paired results incomparable even though both used the same private local model.

The [reference adapter](../scripts/claude_reference_adapter.sh) now replaces the model name with the configured local model and selects effort from the requested tier. It adds `--effort` when the child did not pass one. A fake local Claude executable checked all four mappings and both flag forms without any network request. The adapter was installed only in the disposable `lifeos-claude-ref` account. Its prior script is backed up at `/home/lifeos-claude-ref/.config/lifeos-reference/bin/claude.before-tier-effort-20260928`; copying that file back restores the old mapping.

The reference CLI returned the local model and a successful response for Haiku, Sonnet, and Fable in the [four-tier run](../docs/agents/2026-09-28-native-contract-probe/reference-tiers.jsonl). The first Opus request returned `is_error: true` with no captured error detail. An isolated [Opus retry](../docs/agents/2026-09-28-native-contract-probe/reference-opus-retry.jsonl) returned successfully through the same model. The probe set Bun on `PATH` so native SessionEnd hooks ran; a first attempt without that path produced hook failures and was discarded. The CLI accepted each routed effort, but private gateway telemetry for the actual reasoning effort was not captured.
