# Native command denial at the Hermes approval boundary

On 2026-09-28, the `.212` bridge already aggregated native `PermissionRequest` decisions so a LifeOS denial beat a LifeOS grant. The Hermes host hook still reduced the combined result to a Boolean grant check. A direct call to `check_dangerous_command` with an explicit plugin `deny` and a human callback that approved returned `{"approved": true, "message": null}`. Two new host tests then failed because Hermes presented the human prompt after the denial.

The host change treats an explicit plugin denial as a block when Hermes has identified a recoverable dangerous-command warning. The hardline and user-deny floors run first. A plugin grant cannot bypass a Tirith warning or smart guardian denial. Denials are aggregated across plugins, and the bridge aggregates outcomes across native hooks. The focused host file passed 13 tests; five approval and guard files passed 220 tests. The plugin suite passed 195 tests with 56 optional fixtures skipped. The pinned source preparation test applied eight Hermes and nine LifeOS patches into new trees and passed `git diff --check` in both.

A disposable `.212` profile loaded the installed `lifeos-hook-bridge` through Hermes's real plugin loader. Its synthetic native hook denied `rm -rf /tmp/lifeos-denial-fixture`; `check_all_command_guards` returned `plugin_denied` with zero human prompts. The same profile's hook would allow `rm -rf /`, but Hermes returned a hardline block. These commands were inspected by the guard only and were never executed. The `.212` gateway was restarted on Hermes commit `7c6b3b4d8` with the bridge pinned to public plugin commit `f9d89086947010a377a675584f8dd1e49947ccca`; the user service was active afterward. Production `.211` and `.213` were untouched.

The host code is on `.212` branch `feature/universal-stop-hook`. To roll back this test change, stop the gateway, move that branch back to parent commit `3f74c15f2`, restore the plugin directory from `~/workspace/lifeos-hook-bridge-before-native-denial-20260928.tar.gz`, and restart the gateway. Do not reset a branch with later work without preserving that work first. The full plugin suite on `.212` ran 195 tests with 50 skipped; four expected fixture warnings said `No module named 'tools'`. This probe covers a PermissionRequest raised for a Hermes dangerous-command warning. It does not prove every Claude Code permission mode or every native hook effect.
