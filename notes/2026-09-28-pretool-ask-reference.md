# PreToolUse ask reference probe

Date: 2026-09-28. Claude Code 2.1.272 ran in the isolated `.212` reference account through its private local model. A disposable PreToolUse Bash hook returned an event-tagged `permissionDecision: ask` with reason `Synthetic review request`. In a one-turn, noninteractive run, the hook fired once and the exact Bash call appeared in `permission_denials`. An allow control fired once and had zero permission denials.

A second paired probe allowed up to three turns and used a literal `printf MARKER > effect.txt` command. The allow control created the marker file and had zero permission denials. In the ask case, the hook fired for both a write and a later `cat`. The write created the marker file, while `cat` appeared in `permission_denials`. The model's explanation contradicted the file contents, so this result uses the observed hook events, denial list, and file bytes only. The native ask decision is therefore not a universal block for every Bash form under the reference account's merged settings. The precise interaction with built-in or LifeOS permission rules needs another controlled probe before claiming exact approval timing.

The [probe source](../docs/agents/2026-09-28-native-contract-probe/probe_reference.py), [first results](../docs/agents/2026-09-28-native-contract-probe/results.jsonl), and [effect results](../docs/agents/2026-09-28-native-contract-probe/pretool-effects.jsonl) retain the synthetic commands and summarized data. The probe removed its temporary files after each run. No production installation was used.

Three additional pinned-reference probes registered Bash hooks with matchers `Bash, Read`, `^Ba`, and `*`. Each received one Bash event. The bridge previously skipped the first two and raised `PatternError` for the third. Their [raw results](../docs/agents/2026-09-28-native-contract-probe/matcher-results.jsonl) record the actual dispatched tool names. The bridge now uses the matched event source for SessionStart and SessionEnd, recognizes `*`, checks comma alternatives, and searches regular expressions. The reference one-shot matcher probes ended at the turn cap, so they establish dispatch rather than complete tool execution.
