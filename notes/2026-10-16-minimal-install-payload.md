# 2026-10-16: most of the complete archive is not the plugin

Adrian asks why installing a plugin requires a 288 MB complete-runtime download. The initial release-manager subdirectory is small, but the later managed release includes patched Hermes, patched LifeOS, their Git metadata, and a stock Hermes recovery archive. The current runtime validators require Git HEAD, and complete removal authenticates the stock archive. Removing these entries without changing the contracts produces an invalid package.

A streaming recompression experiment uses the exact 0.7.3 archive. With the same compressor settings, all entries produce 288,144,751 bytes. Excluding both `.git` trees produces 182,219,879 bytes. Excluding those trees and `stock-hermes.tgz` produces 101,017,647 bytes. These are hypothetical layouts, not qualified or installable releases. The experiment measures packaging overhead. It does not establish that recovery and integrity can operate without their current inputs. Raw results are in the minimal-install review directory.

The ten distributed Hermes patch groups total 347,842 bytes. They change 94 paths, including 37 tests or test-runner paths. Applied in order to a disposable copy of the pinned stock Hermes archive, then reversed in reverse order, they restore all 18,243 original regular files with matching contents and permission modes. Ten existing patch-state unit tests also pass. This establishes patch mechanics on the exact supported base. It does not establish safe live activation, arbitrary-version compatibility, dependency compatibility, or complete interruption recovery. An independent Opus architecture review is running before any product design is selected.

Follow-up: Opus recommends split component assets and a private runtime derived from a verified local base, with restricted in-place patching as a separate mode. The primary agent repeats all 38 related tests in the qualified environment and completes the offline source-derivation gate for both programs. Hermes and LifeOS each reproduce the exact qualified tree digest from stock plus the distributed patches. This proves the prepared program trees need not be shipped whole. It does not qualify the proposed installer or its service transactions.

Owner decision, 2026-10-17: Adrian rejects the private-runtime option because the installer must preserve the user's existing tools, plugins, environment, and configuration. The accepted [in-place-only plan](../docs/in-place-installation-plan.md) requires exact compatibility checks, explicit unsupported results, durable original-file recovery, and coordinated Hermes updates. It retains separate verified LifeOS and integration downloads. The existing 0.7.3 runtime replacement path remains published behavior until the redesign passes qualification.
