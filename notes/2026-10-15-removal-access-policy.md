# Returning to stock can change admission

Date: 2026-10-15.

The removal inventory found that the qualified Hermes integration adds Discord channel-only admission in its session-lifecycle patch. The patch checks direct messages, slash commands, and outbound destinations. An unpatched runtime can retain the same YAML while losing those checks. This is a source finding, not a measured stock-runtime exploit.

Complete removal therefore needs a destination-policy test as well as a configuration-preservation test. The proposed first path selects an exact qualified stock runtime and verifies a supported equivalent restriction. If the destination cannot preserve the restriction, the owner review must select explicit Discord disablement. An unchanged token or channel ID does not establish an unchanged audience.

The same inventory found that Hermes launchers and Pulse units belong to the account, while program and installation locks belong to a profile. The first removal implementation must refuse other unverified consumers. Replacing a launcher under one profile lock cannot prove account-wide isolation.

The [independent inventory](../docs/agents/2026-10-15-portability-removal-review/portability-removal-review.md) records exact producers and required acceptance cases. No daily program, service, or channel configuration changed during this investigation.
