# Coordinated ownership setup and configuration return

Date: 2026-10-05. This candidate unit coordinates the existing native backup, reviewed configuration transaction, and private user service barrier. It operates on disposable synthetic profiles. No deployed configuration or service changes.

Preparation checks a qualified dashboard owner, disabled ownership and sharing, a canonical native connector, and the selected service definitions. It records intent before draining gateway, PULSE, and dashboard parent and child writers. It creates a coherent profile and native backup and records a signed configuration plan. It then resumes the original service selection for review. Ownership remains disabled during review.

Apply requires the exact reviewed setup signature. The plan binds the profile, principal, installed alias and physical root, unit selection, original active service selection, backup signature, and configuration signature. A changed configuration, backup, unit definition, or active selection refuses before stopping services. Apply drains again and checks stopped writers immediately before each configuration publication. It disables both Hermes stores before enabling native ownership. It then resumes only the original active services.

Recovery cancels interrupted preparation or returns an interrupted or completed configuration setup. It drains restarted services without replacing the original active selection. It restores exact configuration through the ownership journal, then resumes services. It preserves later facts and forget decisions. Later configuration edits refuse recovery and keep services drained. A completed journal from a previous return can be ignored only when the current configuration still matches the new reviewed backup. An unfinished foreign journal still refuses.

Both failing outputs remain in this directory. The corrected gate passes 11 tests and 23 subtests.

Actual systemd services, control groups, native backups, configuration writes, and retained native references establish the effects. No service results are mocked.
