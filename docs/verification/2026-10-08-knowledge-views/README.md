# Governed native Knowledge command views

Date: 2026-10-08. This candidate uses Hermes `758ad514eb0e800547e015edf05aa18f78b78d82` and LifeOS `5e2f2e8c0abde612da0e99c16c0d07d4ec21b88c`.

The [baseline](before.txt.gz) confirms that review, status, contradictions, and index commands bypass managed authority. Unbound commands expose staging titles and current note labels. The index command writes derived files without an owner grant. The receipt and output-shape checks also fail before delegation exists.

Managed commands now use the native synchronous command algorithms with declared sources. Review consumes admitted staging metadata. Status and contradictions consume registered current notes. Index regeneration consumes the same current corpus and valid harvest state. Physical source, native validation, retirement, byte, and count limits remain active. The declared reader has no physical-file fallback.

The service checks current owner authority after rendering. The [HTTP audience baseline](audience-before.txt) reproduces a later permission change after the final source scan. A final audience check now stops the read response. Index publication uses an unrestricted owner transaction and the existing recovery journal. It publishes all five native index destinations with mode `0600`, including empty domain indexes. Standalone index execution retains its ordinary native destination behavior.

- Exact owner review, status, and contradiction output comparisons with the pinned original command.
- Unbound and revoked refusal, current Discord permission checks, excluded staging metadata, and preservation of unregistered notes.
- Current-source changes during rendering and an actual process exit after the first index publication.
- Recovery of the complete previous index set.
- Neighboring native facts, staged decisions, canonical reads, backups, delegation, background audience checks, Observability Knowledge requests, query controls, installation, capabilities, and patch checks.
