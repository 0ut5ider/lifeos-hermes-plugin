# Governed native rating analysis and reports

Date: 2026-10-05. Role: primary implementation and verification.

Managed LearningPatternSynthesis rating analysis consumes admitted JSON Lines from the fixed native ratings source. The service checks the installed source path, unrestricted owner recall, decoded private content, retirement, current source bytes, and current authority. Private and retired ratings stay outside the native input. Missing context, redirected sources, and revoked accounts refuse delivery.

The native analysis and report formatter retain the authorized fixture behavior. The service anchors the native clock once and validates the selected report path. Read-only owners can analyze ratings with dry run. Publication also requires unrestricted owner write access. The operation journal protects the fixed report, checks its expected previous bytes, and publishes it with mode 0600. Later report edits survive refusal. A subsequent transaction recovers the previous report after actual process death during publication.

## Limits

This unit governs rating analysis and report publication. Hypothesis derivation, recurrence intake, healing fixtures, and their state and logs remain open. The source limit is 256 KiB and 2,048 rows. Supported rows have bounded rating and confidence fields. Report and native transport limits remain explicit. The tests do not establish equivalence for every malformed input.

The public native tools package has no typecheck, lint, test, or build script. Bun processes validate the exercised paths. These fixtures do not prove live private model judgment, scheduled execution, restricted prompts, aggregate ownership recovery, or complete memory activation. Generated reports do not create explicit fact references for every sentence.

No production server, configuration, ownership, or sharing setting changes. The combined release gate remains open.
