The [original baseline](before-output.txt) has seven failures and two passes. The original command permits missing-context planning and status, includes private identity sources, follows redirected sources and tracking destinations, and writes tracking files with mode `0644`. It also writes tracking state after a read-only child refuses publication.

The memory service admits the current watched source set and native plan. The native CLI rechecks that plan before each child. Child processes retain the authenticated context and use their own governed writers. The CLI retains native change detection, action selection, timeout handling, and failed-source retry behavior. It does not hold a memory writer lock while it starts children. Tracking state and logs use the existing recoverable publication journal and mode `0600`. A managed sync lock checks its regular owner file and live process before reuse. Status and dry-run requests do not create that lock.
