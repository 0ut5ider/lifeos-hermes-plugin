# Governed Wisdom readers and cross-frame synthesis

Date: 2026-10-05. Role: primary implementation and verification.

Managed classification, frame loading, and listing consume current admitted native frame snapshots. Cross-frame synthesis and frame-health reports use the same source admission. The native parser, keyword scoring, similarity calculation, report formatting, and four CLI modes retain their original behavior for the authorized fixtures.

The readers require the installed LifeOS root and unrestricted owner recall. Collection bounds directory discovery and uses existing physical-path, private-content, and retirement checks. Private or retired frames stay outside the declared native input. Source or authority changes refuse delivery. Missing context and revoked accounts cannot use a raw fallback.

Report publication also requires unrestricted owner write access. Read-only owners can run dry reports. The existing operation journal protects the fixed principles and health report pair. Publication checks expected destination bytes, source signatures, and current authority. Files use mode 0600. The operation preserves a later report edit and recovers the previous pair after process death between writes.

## Evidence

The original native paths fail seven controls and pass the authorized dry synthesis control. They disclose private and retired frame bodies, publish without current owner authority, follow a redirected source, and create reports with mode 0644. The first candidate passes all eight controls in 4.42 seconds.

The combined gate passes 62 tests and 40 subtests in 53.77 seconds. It includes both Wisdom units, source admission, service operations, and native backup. Three original-native library controls compare classification, frame loading, and listing. Four original-native CLI controls compare exact stdout and report bytes for synthesis, dry synthesis, health, and dry health.

Actual interleavings change the source, owner account, or report after the native renderer returns. Another interleaving revokes authority during actual frame validation. All refuse delivery or publication and preserve the expected previous or later report bytes. An actual exit with status 73 after the first publication leaves the report pair incomplete. A subsequent transaction restores both previous reports.

The recorder saves 12 passing controls with native process output and synthetic published report bytes. Source comparison confirms 52 native files match the prepared distributed tree. All 19 root/runtime patch pairs match. The native memory patch includes the classifier and cross-frame synthesizer. No dependency or patch group is added.

## Limits

These fixtures select the native root explicitly. They do not prove live environment binding, scheduled learning synthesis, model judgment, restricted conversation prompt delivery, the complete reader inventory, aggregate ownership recovery, or activation. Generated reports are native source documents; publication does not claim that each generated sentence becomes an explicit fact reference.

The public tools package has no typecheck, lint, test, or build script. Actual Bun imports and native processes validate the exercised paths. This gate does not establish a complete TypeScript typecheck.

No production server, configuration, ownership, or sharing setting changes. The combined release gate remains open.
