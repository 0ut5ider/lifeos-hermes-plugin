SOURCE notes/2026-09-28-session-end-reasons.md
    1: # SessionEnd reason mapping and resume boundaries
    2: 
    3: Date: 2026-09-28. Target: the pinned Claude Code 2.1.272 reference and the `.212` Hermes test install.
    4: 
    5: [Claude's SessionEnd reference](https://code.claude.com/docs/en/hooks#sessionend) defines `clear`, `resume`, `logout`, `prompt_input_exit`, and `other`. It says an interactive `/resume` ends the previous session with reason `resume`. The bridge was registered on Hermes `on_session_finalize`, so it already ran at a true session boundary. It discarded the supplied Hermes reason and always passed `other` to LifeOS. The `.212` gateway and CLI also switched sessions on `/resume` without emitting `on_session_finalize`. These observations narrowed the issue from a suspected event-cadence problem to missing reason propagation and missing resume finalization.
    6: 
    7: The bridge now maps Hermes `new_session` to Claude `clear`, passes `resume`, `logout`, and `prompt_input_exit`, and maps unrecognized reasons to `other`. The new generic Hermes patch emits `on_session_finalize` after a successful gateway `/resume` switch and before clearing conversation state. The CLI emits it before replacing the current session ID. It passes `resume` through its existing lifecycle helper.
    8: 
    9: The regression failed before each code change. The bridge test observed three `other` reasons instead of `clear`, `resume`, and `other`. The gateway test observed zero finalization calls. The CLI test observed zero finalization calls.
