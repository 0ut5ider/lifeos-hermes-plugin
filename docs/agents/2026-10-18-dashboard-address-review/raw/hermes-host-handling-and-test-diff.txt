    fix(inplace): keep a replaced dashboard's address
    
    With hand-started dashboards now detected, preparation creates a
    standard dashboard unit and stops the hand-started process. That

    0.0.0.0 lost remote access, and with it the releases page. The scan

    validates them, and the created unit uses them. Dashboards on
